# Лабораторная: сигналы (IPC)

Сборка и полный прогон всех заданий (Linux и macOS):

    ./run.sh

| Задание | Файл |
|---|---|
| Уровень 1 (A): `kill -l`, father и три сына | `father.c` → таблица процессов в `ps.txt` |
| Уровень 2 (A): ненадёжные сигналы, `signal()` | `sig_father.c`, `sig_son.c` |
| Уровень 3 (A): сигналы и нити, `pthread_kill` | `thread_sig.c` (режимы 0, 1, 2) |
| Уровни 1–3 (B): надёжные сигналы, `sigaction` | `sigact.c` (`./sigact [сек] [-k]`) |

Ручной запуск из задания: `./sig_father &`, затем `kill -s USR1 <PID>`.
`output.txt` — вывод прогона на Linux.

Особенности macOS:
- в `ps` нет столбцов IGNORED/CAUGHT, поэтому в `ps.txt` показано только состояние процесса;
- режим 0 программы `thread_sig` (kill по идентификатору нити) работает только в Linux.
